# 贴吧清理助手

面向 Windows 10/11 x64 的本地桌面工具，帮助账号本人查询、预览并选择性删除自己发布的贴吧回复、主题帖，以及整理自己的关注与粉丝关系。

本工具不是发帖、刷量、引流、采集他人数据或绕过平台限制的机器人。所有清理操作都必须由用户主动查询、勾选并二次确认，程序不会在后台自动操作贴吧内容。

## 下载

从 [Releases](../../releases/latest) 下载当前版本。每个正式版本只提供一个单文件安装程序，目标电脑无需预装 Node.js 或 .NET。

## 功能

- 多账号独立登录，并可在查询页切换账号。
- 支持内置网页登录、整段 Cookie 解析和 Cookie 分项填写。
- 查询自己的回复、主题帖、关注用户、关注贴吧和粉丝。
- 按日期、关键词和贴吧名称筛选，最多扫描 100 页。
- 全选当前页或全部查询结果，并可调整每页显示数量。
- 清理前预览与二次确认，串行执行，显示进度并支持停止后续操作。
- 本地任务记录、代理设置、安装位置选择及应用内卸载。
