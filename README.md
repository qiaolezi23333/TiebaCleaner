# 贴吧清理助手

面向 Windows 10/11 x64 的本地桌面工具，帮助账号本人查询、预览并选择性删除自己发布的贴吧回复、主题帖，以及整理自己的关注与粉丝关系。


## 下载

从 [Releases](../../releases/latest) 下载当前版本。

## 功能

- 查询和删除、取关自己的回复、主题帖、关注用户、关注贴吧和粉丝。
- 按日期、关键词和贴吧名称筛选，最多扫描 100 页。
